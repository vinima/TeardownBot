# Teardown Bot

A small AI app that answers positioning questions about any developer tool from that company's own web pages, with citations. Anything the pages don't cover is clearly labelled as outside knowledge. Built with Next.js and the Vercel AI SDK, deployed on Vercel, and tracked with PostHog.

New here? [docs/WHAT-IT-DOES.md](docs/WHAT-IT-DOES.md) explains what the app does and how to use it. [docs/CODE-GUIDE.md](docs/CODE-GUIDE.md) explains the code and where to make common changes.
